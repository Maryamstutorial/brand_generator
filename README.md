# 🏷️ Brand Name Generator

A simple **Python beginner project** that generates random brand names by combining a prefix and a suffix.

## 📌 About the Project

This program asks the user how many brand names they want and then randomly generates brand names such as:

```text
cloudlabs
novatech
pixelhub
dataai
```

The program also uses a **set** to avoid duplicate brand names.

## 🚀 Features

* Generate multiple random brand names
* Combine words from two collections
* Use Python's `random` module
* Avoid duplicate brand names
* Take the required quantity from the user

## 🧠 Python Concepts Practiced

* `set.add()`

## ▶️ How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project in VS Code or another Python editor.
4. Run the Python file.
